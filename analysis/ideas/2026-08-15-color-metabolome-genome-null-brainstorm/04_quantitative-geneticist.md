# Partition Variance Before Hunting for Hits: A Two-Level Random-Effects Decomposition of Color

## Persona
**Quantitative Geneticist** — before running a fifth association test, I want to know how much phenotypic variance in a*/b*/C* is even attributable to heritable/genetic structure (species + within-species strain identity) versus plate/batch/measurement noise, because if the genetic variance component is small or entirely between-species, single-feature association tests within R. mucilaginosa were never going to find anything.

## Motivation
Every result so far (univariate, Lasso, ANOVA, all within R. mucilaginosa or small species) is an association test that implicitly assumes there is strain-level heritable variance in color for metabolome features to associate with. But no one has actually partitioned the variance to check that assumption. This is the single most basic quantitative-genetics move — estimate V_G/V_P (broad-sense heritability analog, or here more precisely "repeatability"/phylogenetic heritability) — and it was skipped in favor of five different flavors of hypothesis test, all of which came back null. A quant geneticist's instinct when every test is null is not "try a sixth test," it's "check whether the trait has any transmissible signal left to detect at this level in the first place."

## Connection to Existing Data
- Phase 1 found significant species-level phylogenetic signal for a*/C* (Blomberg's K p=0.02-0.04) but NOT for orange_score (p=0.09-0.15) — that's already a variance-partitioning result, just done at the coarse 17-18-species level and only for one summary statistic (K).
- The color/metabolome cross-validation (control_90_110 vs YPD2, r=0.97 for a*, r=0.99 for b*) gives a direct, ready-made estimate of measurement-level repeatability: ~2-6% of variance is pure inter-measurement noise. That's a lower bound on non-genetic variance, not an upper bound — it says nothing about plate effects, imaging-batch effects, or growth-timepoint effects, all of which could be much larger and would look like "environmental" variance in a heritability decomposition.
- The R. mucilaginosa n=206 dataset with a near-full-panel range of a* within one species is exactly the dataset needed to ask: within this species, does strain identity (a proxy for additive genetic variance, since these are presumably clonal/haploid propagules — repeatability across replicate colonies IS heritability here) explain variance beyond plate/batch?
- If replicate colonies per strain exist in the phenotyping pipeline (need to check upstream Rhodotorula_phenotypes repo), a strain-level random-effects model directly estimates broad-sense H^2.

## Approach
1. Pull the raw (not just per-strain-averaged) colony-imaging measurements from the upstream control_90_110 pipeline — check whether multiple colonies/replicates/plates exist per strain (critical prerequisite; if only one measurement per strain exists, repeatability can't be separated from a single value and this must be reframed as a between-strain-only nested ANOVA).
2. Fit a nested random-effects / mixed model: color ~ 1 + (1|species) + (1|strain:species) + (1|plate or imaging_batch, if recorded), separately for a*, b*, C*, and orange_score, using REML (lme4 in R or comparable).
3. Extract variance components: V_species (between-species), V_strain (within-species, i.e., the strain-level heritable component the association tests are implicitly relying on), V_batch/plate, V_residual. Compute proportion of total variance at each level, with bootstrap CIs (resample strains within species, and residuals within strain, to respect the nesting).
4. Compare V_strain (within R. mucilaginosa specifically, since that's the species carrying essentially all the association-test statistical power) directly against the 2-6% measurement noise floor from the YPD2 cross-validation. If V_strain within R. mucilaginosa is itself only marginally above that noise floor, that is a direct, quantitative explanation for every null result reported so far — not "metabolome doesn't explain color" but "there is barely any strain-level color variance left to explain once species and batch are accounted for."
5. If V_strain is substantial (say >20-30% of total variance within R. mucilaginosa), that reopens the case for association testing but flags that a chunk of the previously-tested "signal" may actually be batch/plate confound riding along with metabolome batch effects — which would also explain the colony-area/cell-fraction-metabolite confound already noted as an unexplained side finding (both could trace to a shared plate/batch/growth-timepoint effect).

## Expected Insights
A concrete, quantitative verdict on whether the four+ null association results are null because (a) there's no biological link between the measured metabolome and color, or (b) there's essentially no heritable strain-level color variance to link to in the first place, or (c) a shared batch/plate confound is inflating apparent noise on both sides and masking real signal. This directly reframes "is metabolomics associated with color" as "how much genetically-determined color variance exists at the resolution we're testing," which is the correct diagnostic question a quant geneticist asks before concluding a trait has no molecular basis discoverable in this dataset.

## Feasibility
- Effort: Low
- Data ready: Needs preprocessing — requires locating raw/replicate-level (not strain-averaged) colony measurements in the upstream Rhodotorula_phenotypes imaging pipeline, plus plate/batch metadata; if only strain-level averages exist, effort stays low but the model design must be simplified.
- Methods available: Standard tools (lme4/nlme in R, or statsmodels MixedLM in Python; nothing custom needed)
- Key risk: If replicate-level data was not retained (only per-strain final phenotype values were exported to this repo), V_strain and residual/measurement variance become confounded and the decomposition degrades to a between-strain-only ANOVA — still informative, but weaker than a true heritability estimate.

# Build a Metabolome Polygenic Score (Not Single-Feature Hits) and Test It Against Phylogenetically-Corrected Color

## Persona
**Quantitative Geneticist** — color is very unlikely to be governed by one dominant metabolite; if it has any molecular basis at all it's more plausibly an emergent readout of a polygenic-style aggregate of pathway flux (carotenoid/melanin-adjacent pathways, membrane lipids, redox state), so the right test is a properly cross-validated, phylogenetically-aware aggregate score, not a per-feature p-value hunt — Lasso in n=206 is already a step in that direction but was run without an explicit GxE/pathway-structuring lens or a permutation-calibrated null tuned to the actual polygenicity expected.

## Motivation
Quantitative genetics learned decades ago (from the "missing heritability" era of human GWAS) that single-locus/single-feature tests are underpowered for polygenic traits, and the fix was not more stringent single-marker thresholds but aggregate/polygenic scores built from many small, individually-nonsignificant effects, validated out-of-sample. The project already tried one aggregate approach (sparse Lasso) and got a negative cross-validated R^2 — but sparse L1 regression is a poor match for a truly polygenic (many small, non-sparse, correlated) signal; it's built to find a few large effects, not spread signal across thousands of correlated MS2 features. A ridge-style or aggregate-score approach, done at the right level (within-species, with pathway/compound-class structuring), hasn't been tried, and it directly matches how a geneticist would treat "10,949 compound groups, 4.8% annotated" — as candidate loci for a polygenic score, not independent hypotheses.

## Approach
1. Restrict to R. mucilaginosa (n=206, most power) and, separately, the whole panel with phylogenetic block structure preserved (17-18-species blocks) for a second confirmatory run.
2. Instead of Lasso (L1, sparse-effect-seeking), fit ridge regression or an elastic net biased toward the ridge end (e.g., alpha=0.1-0.2) on cell-fraction metabolite abundances (the fraction already flagged as confounded by colony area, so include colony area as a covariate/decoy check exactly as done in prior negative controls) against a* and C*, using nested cross-validation to get an honest out-of-sample R^2 and its permutation null (shuffle strain labels respecting phylogenetic blocks, 1000+ permutations) — this is the aggregate/polygenic-score analog of a PRS.
3. Additionally build a "pathway score": group the 10,949 compound groups by coarse chemical class (using whatever SIRIUS class-level annotations exist even for the 4.8% annotated fraction, e.g., carotenoid-adjacent, isoprenoid, phenolic/melanin-precursor classes) and sum/average abundance within each class as a small number of biologically-motivated composite predictors — test these against color with far fewer degrees of freedom than the full feature matrix, which is more appropriate given only 4.8% annotation coverage and prevents the full-feature model from being dominated by noise features.
4. Explicitly test whether ridge/aggregate R^2 exceeds the Lasso/univariate null by a meaningful margin, using the colony-area decoy trait as a positive-control benchmark run through the identical aggregate pipeline (should recover strong R^2, as it did for the univariate/other methods) to confirm the aggregate method has power before trusting a null.
5. If the ridge/pathway-score approach is also null (which is plausible given four prior null results), that is a genuinely strong quantitative-genetics conclusion: color is not even weakly polygenically encoded in the measured metabolome, at the resolution/coverage available — worth stating explicitly as a finding rather than leaving the space of "aggregate methods" untested.

## Expected Insights
Either (a) a clean win — a ridge/pathway aggregate score achieves non-trivial cross-validated R^2 where sparse Lasso failed, revealing a genuinely polygenic (not single-feature) metabolome-color relationship that the earlier association tests were structurally incapable of detecting, or (b) a strengthened null — ridge, pathway-aggregation, AND sparse methods all fail, which upgrades "no metabolome feature is significantly correlated with color" to the much stronger and more publishable claim "color has no detectable polygenic signature in the measured cell-fraction metabolome at any tested level of aggregation," closing off this line of inquiry with actual statistical weight rather than leaving it as an accumulating pile of individually-inconclusive negative results.

## Feasibility
- Effort: Medium
- Data ready: Mostly — metabolite abundance matrix and color phenotype exist; pathway/class-level grouping needs the SIRIUS re-run (in progress) or a coarser interim classification (e.g., MS2 spectral clustering/GNPS-style molecular families) if class annotation coverage stays too low to use.
- Methods available: Standard tools (glmnet/scikit-learn ridge + nested CV; permutation testing already established in prior analyses in this project)
- Key risk: With only 4.8% SIRIUS-annotated features, the pathway-score version may be too underpowered/noisy to trust regardless of outcome; and if colony n per strain is small, nested CV within R. mucilaginosa could be unstable — needs the sample-size sensitivity check the robust-analysis convention pack already mandates for this repo.
