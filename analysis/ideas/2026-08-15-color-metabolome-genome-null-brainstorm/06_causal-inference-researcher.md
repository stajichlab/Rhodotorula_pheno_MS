# Determine Color's Causal Role Relative to Colony Area Before Trusting Any Null

## Persona
**Causal Inference Researcher** — I don't test associations against a phenotype until I've drawn the DAG and classified every other measured variable as confounder, mediator, or collider with respect to the edge I actually care about.

## Motivation
The project has silently assumed colony area is a "negative control decoy" — a trait that shares phylogenetic structure with color but has no causal path to metabolite abundance, so a null area-metabolome result would validate the pipeline and a positive one would flag artifact. But that assumption was never tested, and the result actually observed is the *opposite* of what a decoy is supposed to do: area lit up strongly (15-20% of compound groups, cell fraction, both between- and within-species) while color stayed at zero. A decoy that turns out to be real doesn't validate the pipeline — it tells you the decoy was mis-specified. As a causal thinker, my first move is not "is color associated with metabolites" but "what is the actual causal graph among genotype, growth/development stage, colony area, colony color, and cell-fraction metabolite abundance, and where does area sit in it." Area could be:
- A **confounder** of color-metabolome (shared upstream cause, e.g. inoculum density or plate position) — conditioning on it would be correct and might reveal a partial color effect currently masked.
- A **mediator** on the genotype → biomass/growth-rate → metabolite pathway that has nothing to do with pigment — in which case its association with metabolites is real but causally irrelevant to the color question, and calling it a "decoy" was the wrong framing from the start.
- A **collider** if both color and metabolite abundance independently influence how area was measured/segmented (e.g. darker colonies are easier/harder to threshold in the imaging pipeline, biasing area estimates) — conditioning on area in that case would *induce* a spurious color-metabolite link, not remove one, which is the opposite of what conditioning-as-nuisance-control assumes.

## Connection to Existing Data
The project has run 5 null tests for color (whole-panel Spearman + phylo block permutation, within-mucilaginosa univariate, 2 small-species univariate, Lasso, ANOVA/pattern test), all null, all using species/clade blocks as a nuisance-correction structure. In every one of these, colony area was used as a decoy but its own relationship to color was never quantified, despite both being measured at the same imaging timepoint from the same colonies and species differing systematically in typical colony size. Area's real, strong signal is specifically in the cell-fraction (not supernatant) metabolome — cell fraction is exactly what you'd expect to be driven by biomass/growth-stage, which is mechanically almost the same thing as colony area at a fixed timepoint. That's a strong hint area is standing in for "how much colony was there to extract, and at what physiological stage," which is a biomass/growth-rate mediator, not a decoy at all.

## Approach
1. **Formally quantify color–area correlation** (not yet done per the brief): compute L*/a*/b*/C* vs. log(colony area) both within R. mucilaginosa (phylogenetic GLS, n=206) and between species (species-mean regression, n=17-18), reporting effect size + CI, not just a p-value. This single missing analysis determines which DAG structure is even plausible.
2. **Draw and pressure-test 3 candidate DAGs** explicitly (as a figure, not prose): (a) genotype → {color, area} independently, area confounds nothing; (b) genotype → growth-stage/biomass → area → cell-fraction-metabolome, with color a separate independent branch (decoy interpretation correct, area is a mediator on a *different* pathway — irrelevant to color, should be dropped from the analysis entirely, not conditioned on); (c) genotype → growth-stage → {area, metabolome} AND growth-stage/extraction-timing → color (color and metabolome share a latent confounder via developmental stage, e.g. pigment maturation is time-dependent) — in this DAG, failing to condition on growth-stage/extraction-timing is what's producing the null, and area is a decent *proxy* for that missing confounder.
3. **Test DAG (c) directly**: refit the existing whole-panel and within-mucilaginosa color-metabolome correlations *with colony area entered as a covariate* (partial correlation / PGLS with area as covariate), separately for cell fraction and supernatant. If color-metabolite associations emerge in cell fraction once area is partialled out, that's direct evidence area was a confounder masking a real color signal via a shared growth-stage cause — the opposite of "decoy," and a reason to redo tests 1-5 with area-adjusted color residuals instead of raw color.
4. **Test for the collider scenario**: check whether the imaging pipeline's area-extraction step depends on colony pigmentation (e.g. by re-running the segmentation algorithm's edge-detection thresholds on a stratified color-diverse image subsample, or simply checking if measurement noise/CV in area scales with a*/b* extremity). If segmentation is color-sensitive, area is contaminated as a covariate and should never be conditioned on for the color question, only inspected as a marker of pipeline artifact.
5. **If DAG (b) wins** (area is purely a biomass mediator unrelated to color): explicitly reclassify area in project documentation as "biomass/growth-stage proxy," not "negative control decoy," and design a *replacement* negative control that is verifiably independent of both metabolism and color's causal ancestry (e.g. a phenotype known to be purely measurement-noise-driven, or a permuted/shuffled color vector with matched phylogenetic autocorrelation structure) — because a decoy that turns out to have a real, mechanistically sensible causal story is not doing decoy duty.

## Expected Insights
Either (i) you find color and area are strongly correlated and area was masking/confounding a genuine cell-fraction color-metabolite signal — meaning tests 1-5 need to be rerun with area-adjusted color, a substantive redirection of the whole null result; or (ii) you find area and color are weakly/non-correlated, area's signal is cleanly a biomass-mediator artifact unrelated to pigment biology, and the 5 nulls stand but the project's negative-control logic needs to be rewritten and a better decoy substituted — either way, this closes a real gap (color-area correlation was never measured) that currently lets a load-bearing assumption go unchecked.

## Feasibility
- Effort: Low
- Data ready: Yes — L*/a*/b*/C*, colony area, and the tree/species blocks are already computed and sitting in analysis/YPD/color_shape_growth/ and analysis/copper/ outputs.
- Methods available: Standard tools (partial correlation, PGLS with covariates, standard DAG reasoning) — no custom implementation needed beyond adding one covariate to existing PGLS scripts.
- Key risk: If area turns out to be a collider (segmentation depends on pigmentation), "just add area as a covariate" is actively wrong and would need to be caught before anyone reruns tests 1-5 with area-adjustment — step 4 has to happen before step 3's results are trusted, not after.

# Stop Treating Species/Clade as Pure Nuisance: A Genotype-to-Color Path-Specific Reanalysis

## Persona
**Causal Inference Researcher** — I distinguish "adjust away the confounder" from "adjust away the causal pathway," and phylogenetic correction is exactly the kind of procedure that quietly does the second while claiming to do the first.

## Motivation
Every one of the 5 null tests uses species/clade as a blocking or permutation structure to remove phylogenetic non-independence — standard practice, and correct *if* the causal question is "does color predict metabolite abundance for reasons other than shared ancestry." But the project has never separately asked the prior question: does genotype (species identity, clade membership) causally determine colony color in the first place? If genotype → color is a strong, near-deterministic path (which is biologically very plausible for pigmentation — carotenoid/melanin pathways are classic species- or clade-level fixed traits in Rhodotorula, this genus is literally named for its color), then phylogenetic block permutation, by construction, destroys almost all of the variance in color that exists in the data, because most of that variance IS the between-clade component. You'd be testing "does within-species color noise correlate with metabolite noise," a much weaker and possibly under-powered question, while discarding the between-species color-metabolite covariation that might be the real, biologically meaningful signal (mediated entirely through the genotype → pigment-pathway and genotype → other-metabolism branches sharing a genetic root).

## Connection to Existing Data
The panel is 206-216 of 300-310 strains being a single species (R. mucilaginosa) with 17-18 species total — i.e., between-species variance dominates the design, and species-level blocking in a whole-panel test with ~17 blocks is a small number of exchangeable units to permute against, likely underpowered and, more importantly, is stripping out exactly the axis (species-level pigment divergence) where a genotype-color-metabolism link would most plausibly live. The within-mucilaginosa tests (univariate, Lasso, ANOVA) sidestep the blocking-power issue by working within one species where phylogenetic structure is real strain-level relatedness, not simply "which of 17 species" — but they're also, by construction, only sensitive to whatever color-metabolite covariation exists *within* one clade's genetic background, which could be genuinely near-zero even if a strong between-clade effect exists (e.g., if R. mucilaginosa's carotenoid pathway is closer to fixed/saturated and doesn't vary metabolically the way it might across, say, R. mucilaginosa vs. a non-pigmented or differently-pigmented sister species). The genome side of the project (BFD, 276-278 strains, full annotations + tree) has never been connected to color at all — this idea is also the natural first genotype-color test, prior to and informing any metabolome test.
Also directly relevant: no genome<->color association has been attempted yet, despite the BFD tree being available — this idea proposes that as step 1, not as a separate future task.

## Approach
1. **Quantify the phylogenetic signal in color directly** (Blomberg's K / Pagel's lambda on the pruned tree for L*/a*/b*/C*, both the 146-strain and 134-strain trees already built) — if lambda is near 1 (strong phylogenetic signal, i.e., color is basically a clade-fixed trait), that is itself the headline finding explaining why permutation-based tests are structurally underpowered to detect a color-metabolite link, and it should be reported as a finding regardless of what follows.
2. **Decompose color-metabolite covariation into between- and within-clade components explicitly** (a phylogenetic ANOVA / hierarchical variance-partitioning approach, e.g., fitting color ~ metabolite with random effects for species vs. residual, or simply running the whole-panel Spearman on species-mean color vs. species-mean metabolite abundance, n=17-18, as a *deliberately unblocked* between-species test) rather than only ever testing the within-clade residual (current permutation approach) or the single large-clade-only subset (current mucilaginosa-only tests). This directly tests the piece of variance the current pipeline structurally cannot see.
3. **Run the genotype → color test that's never been done**: using the BFD tree/annotations, test whether known carotenoid/pigment-pathway gene presence/absence, copy number, or sequence divergence (e.g., candidate genes like crtYB, crtI, crtE homologs if annotated, or unbiased GWAS-style gene-presence association) predicts CIELAB color across the 276-278 BFD strains, with the tree used properly (PGLS or phylogenetic mixed model) — this is the actual genotype-color causal link the project is missing, and it's a precondition for interpreting any color-metabolome test causally (if genotype robustly explains color, then color is a marker of genotype, and "color vs. metabolome" should really be reframed as "does this genotype-marked-by-color also predict metabolome," i.e., a mediation question, not a direct-effect question).
4. **If step 3 finds real genotype-color hits and step 2 finds real between-clade color-metabolite covariation**, formally test mediation: does the pigment-pathway genotype signal account for the between-clade color-metabolite link (genotype → color and genotype → metabolome as a fork, color not causal for metabolome) versus color itself sitting on the causal path (genotype → color → metabolome, e.g., pigment intermediates are literally shared/precursor metabolites detected by the LC-MS)? This distinguishes "color is a confounded correlate of genotype-driven metabolism" from "color pathway chemistry directly shows up in the metabolome," which are different scientific claims with different follow-ups.
5. **Reframe the write-up**: whatever the outcome, replace "color vs. metabolome is null" with a variance-partitioned statement — e.g., "no within-clade color-metabolite association (tests 1-5, confirmed); between-clade association [present/absent, effect size]; phylogenetic signal in color is [lambda]; genotype-color link [present/absent via BFD]" — because the current single "null" verdict conflates several distinct causal claims that this analysis would cleanly separate.

## Expected Insights
Most likely outcome: color turns out to have high phylogenetic signal (lambda near 1), meaning the current tests were essentially asking "does color vary meaningfully at all after removing clade" — and the true test of whether pigment genetics connect to metabolism has never actually been run. This reframes 5 null results from "color and metabolome are causally disconnected" to "we haven't yet tested the between-clade axis where a link would live," which is a materially different and more actionable conclusion, and directly motivates finally connecting the BFD genome data to color (currently an acknowledged gap).

## Feasibility
- Effort: Medium (Blomberg's K/lambda and species-mean correlation are near-trivial with existing outputs; the BFD genotype-color GWAS-style test is the heavier lift, needs candidate-gene curation or a proper phylogenetic mixed-model/GWAS framework for ~276 strains)
- Data ready: Mostly — color, metabolome, and both pruned trees (146-strain, 134-strain) already exist; BFD functional annotations exist but have never been joined to the color phenotype table, so that join is new work
- Methods available: Standard tools for steps 1-2 (phytools/ape/caper for K, lambda, PGLS); step 3 needs either a targeted candidate-gene approach (fast, standard) or a more research-grade genome-wide association approach if candidate pigment genes aren't cleanly annotated in BFD
- Key risk: With only 17-18 species-level units, the between-clade test in step 2 is inherently low-powered (few independent data points) even though it targets where the real variance lives — a between-clade null would be genuinely ambiguous (true absence of effect vs. insufficient species-level replication) and should be reported with that caveat, not oversold as a confirmed negative
