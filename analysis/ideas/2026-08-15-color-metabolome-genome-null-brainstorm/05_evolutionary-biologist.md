# Convergence-Restricted Association Test: Do Independent Color-Gain Events Share Molecular Correlates?

## Persona
**Evolutionary Biologist** — convergent phenotypes are the natural experiment that pooled or single-species designs are structurally blind to, because they ask "does trait X correlate with trait Y across all my samples" instead of "did the SAME transition happen more than once, and if so, did it happen the same way."

## Motivation
An evolutionary biologist's first move on a "trait shows no linear correlation with a molecular readout" result is to ask whether the trait even behaves as a single continuous axis across the tree, or whether it is really a small number of discrete gain/loss events scattered across independent branches. If darker/redder color evolved 3+ times independently (as the existing convergent-color-evolution screen already hints for R. glutinis, R. sp. clade I, and R. diobovata relative to R. dairenensis), then pooling all 276-278 strains together and asking for a genome-wide or metabolome-wide linear correlation is exactly the design that cancels convergence signal: shared ancestry among the *non*-convergent (pale) majority (206+ R. mucilaginosa strains) dominates the covariance structure and swamps a real but sparse repeated-origin signal. This is the textbook contrast between "phylogenetic regression treating color as inherited-once" and "did independent origins converge on the same underlying chemistry/genetics" — the latter requires explicitly identifying the origins first.

## Connection to Existing Data
- The Phase 1 orange-color composite score and species ranking already exist (R. taiwanensis, R. sphaerocarpa, R. glutinis, R. dairenensis at top).
- The convergent-color-evolution screening step (phylogenetic distance from R. dairenensis vs. orange-score rank) already flagged R. glutinis, R. sp. clade I, and R. diobovata as phylogenetically distant, above-average-orange candidates — this is sitting unused as a "crude signal."
- The strain-level tree (276-278 taxa, PHYling/FastTree) and species-level pruned tree (17-18 tips) both exist and are already used for PGLS blocking in the null CIELAB-vs-metabolome tests.
- All 5 prior tests (whole-panel pooled + PGLS, R. mucilaginosa-only) are null for color vs. metabolome abundance — but none of them isolated the convergent lineages as a distinct contrast group; they either pool everything or restrict to the single largest (least color-variable) species.
- BFD genome annotations (Pfam, MEROPS, CAZy) exist for the same strain set but have never been tested against color at all.

## Approach
1. Formalize ancestral state reconstruction of the orange/color composite score on the species-level (or a well-resolved strain-level subtree) using `ape`/`phytools` (e.g., `fastAnc`, stochastic character mapping `make.simmap` on a discretized high/low color state) to identify the minimum number and location of independent color-gain transitions on the tree — do not just eyeball phylogenetic distance as the current screen does.
2. Alternatively/additionally, run an OU regime-shift detector (`l1ou` or `bayou`) directly on the continuous CIELAB a*/C* trait mapped onto the strain-level tree to let the data nominate shift points rather than assuming R. dairenensis is the reference lineage — this removes the anchoring bias baked into the original "distance from R. dairenensis" framing.
3. For each independently-inferred color-gain branch/clade, pull the terminal strains and metabolome samples (cell fraction, since that's where the colony-area confound already lives and where CIELAB is scored) and construct a "convergence contrast set": each origin's darker clade vs. its own phylogenetically nearest paler sister clade — this is a phylogenetically-independent-contrasts design, not a pooled regression.
4. Test whether the SAME metabolite features (or the same MS2 spectral network / molecular family, useful even pre-SIRIUS-annotation) are enriched in the darker sister of each independent contrast pair — this is the classic convergence test (e.g., a rank-based concordance test across contrast pairs, or a permutation test shuffling which sister is "dark" within each pair). A true convergent pigment pathway should show the *same* feature(s) recurring across origins even if no single feature correlates with color when strains are pooled.
5. Run the parallel version on BFD genome annotations (Pfam/CAZy gene family copy number, presence/absence) across the same independent contrast pairs — looking for convergent gene family expansions/losses (e.g., carotenoid/melanin-pathway-adjacent Pfams) co-occurring with the same darker-lineage transitions, since genome<->color association has never been attempted in this project.
6. Cross-reference: do the metabolite features and genome features that recur across independent origins point to the same pathway (e.g., carotenoid biosynthesis, a MEROPS peptidase family linked to pigment turnover)? This is the payoff question a convergence design can answer that a pooled test cannot even ask.

## Expected Insights
Either (a) a small set of features/gene families recur across 2-3+ independent color-gain events, providing the first positive, mechanistically interpretable signal in a project that has been null 5/5 times — and directly explains why pooled/single-species tests missed it (the signal is real but restricted to ~3 lineages out of 17-18 species, diluted to noise by 206 R. mucilaginosa strains with no color-gain event at all); or (b) confirmation that even convergence-restricted contrasts are null, which is a much stronger and more publishable negative result than the current pooled nulls, because it rules out "the phylogenetic correction washed out a real convergent signal" as an explanation and points more firmly toward color being decoupled from the sampled metabolome/genome features (or driven by regulatory/environmental variation not captured in either dataset).

## Feasibility
- Effort: High
- Data ready: Mostly (tree, CIELAB scores, metabolome table, BFD annotations all exist; discretization/regime-shift modeling and contrast-pair construction need to be built)
- Methods available: Standard tools (`ape`, `phytools`, `l1ou` or `bayou` in R) but the convergence-contrast-pair testing framework itself is custom and needs careful design (esp. multiple-testing correction across many candidate contrast pairs and features)
- Key risk: With only 3-4 candidate independent origins and small clade sizes (R. sp. clade I, R. diobovata may be n=1-a few strains), statistical power for the per-origin contrasts may be very low; this is fundamentally a small-N-of-independent-events design (N = number of transitions, not number of strains), which is the correct evolutionary unit of replication but may leave the test underpowered regardless of how it's built — should be framed explicitly as a discovery/hypothesis-generation pass, not a confirmatory test.

# Environment/Ecology as the Missing Selective Axis: Does Isolation Habitat Predict Color Independently of (or Jointly With) Phylogeny?

## Persona
**Evolutionary Biologist** — pigmentation in free-living microbes is rarely selectively neutral; UV exposure, desiccation, oxidative stress, and substrate chemistry are classic drivers of fungal/yeast melanization and carotenoid production, so an ecologist's reflex on a null color-metabolome result is to ask whether the causal variable is environmental rather than intrinsic-biochemical, and whether that environmental signal is even distributed independently of phylogeny (a confound that would make any naive "color ~ environment" test spurious in exactly the way the metabolome tests already worried about for color ~ metabolome).

## Motivation
Colony color in this panel was measured under one standardized condition (control_90_110, Cu=0mM YPD) specifically to strip out plastic/environmental response and isolate a constitutive trait — which is the right design for a controlled experiment but throws away the question of whether the constitutive trait itself is a fossil of past selection by the strain's original isolation environment (soil UV/desiccation vs. marsh_tidalflat salinity/anoxia vs. plant-associated conditions). This project's strain metadata already carries Origin (geographic) and Environment (isolation substrate/habitat) fields that have not been used at all in the color/metabolome/genome work described. An evolutionary biologist would treat "constitutive color measured in a common garden" as precisely the design that lets you ask whether ecological history left a heritable signature — a classic common-garden / reaction-norm logic — and would also flag that if Environment correlates with phylogeny (e.g., certain species are disproportionately soil-derived), any naive environment-color test needs the same PGLS-style correction already applied to the metabolome work, or it will manufacture a false-positive "ecology explains color" result that is really just species identity in disguise.

## Connection to Existing Data
- Strain metadata already has Origin and Environment fields "for many strains" — described in project context but not mentioned as used in any analysis to date.
- The species-level pruned tree (17-18 tips) and strain-level tree (276-278 taxa) are both already built and used for PGLS in the existing color/metabolome pipeline (`analysis/YPD/color_shape_growth/scripts/02_pgls_analysis.R`, `analysis/copper/scripts/02_pgls_analysis.R`), so the phylogenetic-correction machinery is reusable rather than needing to be built from scratch.
- CIELAB L*/a*/b* colony color and colony area are both already scored under the canonical control_90_110 condition for the full strain panel.
- The unexplained colony-area confound on cell-fraction metabolite abundance is a live open thread in this project — environment/substrate origin is a natural candidate covariate to test against that confound too (e.g., does isolation substrate predict growth rate/colony area under standard YPD, suggesting a domestication/adaptation-to-lab-media signature that differs by ecological origin?).
- The R. mucilaginosa-only null test (n=206) is the single largest species and plausibly spans the widest range of Environment/Origin values of any species in the panel — an ideal internal test bed for an environment-vs-color test that holds phylogeny at the species level constant while still varying ecology, complementary to the convergence idea above which varies phylogeny while (implicitly) ignoring ecology.

## Approach
1. Audit completeness and encoding of Origin/Environment fields across the full strain metadata table (likely in BFD/samples.csv or a linked strain metadata file) — categorize Environment into a small number of ecologically meaningful classes (e.g., soil, marsh/tidalflat, plant-associated, marine, clinical/other) and flag how many strains have each field populated, since this determines whether the test is panel-wide or restricted.
2. Test Environment as a predictor of CIELAB a*/C* (and separately, colony area) using PGLS with the species/strain tree as the correlation structure (reusing the existing `02_pgls_analysis.R` scaffolding), reporting effect sizes and CIs per the repo's robust-analysis convention — this directly tests the "isolation habitat left a heritable pigmentation signature" hypothesis under proper phylogenetic control.
3. Run the equivalent test restricted to R. mucilaginosa alone (n=206, single species, so phylogenetic non-independence within-species is weaker but not absent given ~206-216 strains) to see whether within-species ecological variation in isolation substrate predicts color independent of the between-species phylogenetic signal — this is the natural ecological complement to the existing within-species metabolome null.
4. Cross-tabulate Environment against the convergent color-gain lineages identified in the companion idea (R. glutinis, R. sp. clade I, R. diobovata, R. dairenensis) — do independently-evolved darker lineages share an isolation environment (e.g., all soil/high-UV-exposure), which would suggest a specific selective driver behind the repeated color gains, versus scattered/heterogeneous environments, which would argue against a single ecological driver and favor drift or an unmeasured pleiotropic cause?
5. Extend the same Environment covariate test to the colony-area/cell-fraction-metabolite confound already flagged as unexplained — test whether isolation substrate predicts colony area (a proxy for growth rate on standard YPD), which would suggest strains from certain environments are systematically better/worse adapted to lab culture conditions, a plausible and testable explanation for that open side finding.

## Expected Insights
A positive Environment-color association (even modest effect size) would be the first non-null structural result in the color axis of this project and would reframe the entire "why is color variable" question from a pure biochemistry/metabolome search toward an ecological-selection narrative — particularly valuable if it converges with the convergent-lineage list from the companion idea (i.e., independently-evolved dark lineages disproportionately drawn from one environment class). A null result here is still informative: it would argue that color variation in this panel is closer to phylogenetically inherited "fixed" trait or drift-driven, rather than an active adaptation to isolation habitat, sharpening the interpretation of the existing metabolome nulls. Either outcome directly informs whether Environment should be added as a covariate/blocking factor in future metabolome/genome-color tests (the same way phylogeny already is), potentially resolving confounding not yet considered in the 5 completed tests.

## Feasibility
- Effort: Low (for the core PGLS-with-environment test) to Medium (for the cross-tabulation against convergent lineages and the colony-area extension)
- Data ready: Needs preprocessing (Origin/Environment field completeness/encoding audit is the main upfront cost; core color, tree, and PGLS scaffolding are already in place)
- Methods available: Standard tools (existing `02_pgls_analysis.R` pattern extends directly to a categorical Environment predictor)
- Key risk: Environment/Origin fields may be sparsely populated or unevenly distributed across species (e.g., if soil-origin strains are almost all R. mucilaginosa), which would make Environment and species/phylogeny nearly collinear and limit the test's power to distinguish "ecology" from "which species this happens to be" — worth checking field completeness and cross-tabulating Environment x species before investing in the full PGLS run.
