# Targeted Carotenoid Extraction + APCI/APPI-MS, Bypassing the Untargeted ESI Pipeline Entirely

## Persona
**Natural Products / Analytical Chemist** — I think in terms of chromophores and ionization physics first, statistics second: if the molecule never made it into the ion source in a detectable charge state, no amount of downstream modeling will resurrect it.

## Motivation
Carotenoids are the textbook case of "real biology, invisible metabolomics." Torulene and torularhodin are long, fully conjugated polyene chains (9-13 conjugated double bonds) with essentially no ionizable heteroatoms except torularhodin's terminal carboxylic acid. In standard ESI(+)/ESI(-) LC-MS as used in most untargeted metabolomics pipelines (including EverythingBagel-style workflows), carotenoids ionize poorly and inconsistently — they prefer atmospheric pressure chemical ionization (APCI) or atmospheric pressure photoionization (APPI), or they show up as [M+H-H2O]+ or in-source fragment ions that get scattered across dozens of "features" rather than consolidated into one clean adduct group. They are also notoriously photolabile (isomerize/degrade under ambient light in minutes to hours) and thermolabile, and normal-phase vs. reversed-phase C18 chromatography gives very different recoveries for the free vs. esterified forms. A chemist's first move on seeing "zero hits for torulene/torularhodin, only 3-4 weak class-level SIRIUS calls" is not "the biology is absent" — it's "check whether the extraction and ionization conditions could plausibly see this molecule class at all."

## Connection to Existing Data
- Project data explicitly note only 4.8% (790/16,332) of features have ANY SIRIUS annotation, and of those only 3-4 got a "Carotenoids (C40, β-β)" / "Apocarotenoids(ε-)" NPC-class call — described as class-level guesses with implausible proposed structures, and SIRIUS is flagged as "known to be weak on carotenoids." No literal torulene/torularhodin name hits.
- The phenotype being modeled (CIELAB a*/L*/b*) is a bulk colony-color measurement whose chromophoric basis in Rhodotorula is presumptively carotenoid (torulene = orange-red, torularhodin = its carboxylic acid oxidation product, contributing red/pink hues) — yet the untargeted LC-MS2 pipeline was never designed or validated against authentic carotenoid standards.
- All 5 statistical tests (whole-panel, within-species, Lasso, k-means/Kruskal-Wallis) used the *existing* 16,332/10,949-feature untargeted dataset as the exposure variable. If carotenoids are systematically under-detected, mis-annotated, or split into multiple weak partial-adduct features across that table, every one of those tests is testing "does color correlate with the noise floor of a molecule class the assay can't reliably quantify" — a null result there is uninformative about the true biology, not evidence against a carotenoid-color link.
- The pellet vs. supernatant fractionation split is itself a clue: carotenoids are lipophilic, cell-membrane/lipid-droplet-associated pigments — they should be almost entirely in the pellet fraction, never in supernatant. The "colony area confounds cell-fraction (not supernatant) metabolite abundances" side finding is exactly the compartment where carotenoids would live, and warrants a targeted look before being filed as unrelated.

## Approach
1. Pull frozen/archived pellet aliquots (or re-grow a representative stratified subset — say 24-40 strains spanning the panel-wide a* range, oversampling extremes) and do a dedicated saponification + hexane/acetone/ethyl-acetate carotenoid extraction under gold/red safelight, on ice, with BHT as antioxidant — standard carotenoid analytical chemistry, not the general polar/semi-polar solvent system used for the untargeted panel.
2. Run this extract on reversed-phase C30 (not C18 — C30 is the standard carotenoid-resolving phase for cis/trans and structural isomers) LC coupled to APCI or APPI in both polarities, spiked with authentic torulene/torularhodin/β-carotene standards (available commercially or from a reference lab) for retention time and MS/MS fragmentation matching — not SIRIUS de novo ID.
3. Quantify torulene, torularhodin, and any intermediate pathway pigments (γ-carotene, neurosporene, HKG-related precursors from the fungal carotenogenesis pathway: GGPP → phytoene → lycopene → γ-carotene → torulene → torularhodin) by external calibration curve against the standards.
4. Regress CIELAB a*/b* directly against this small, targeted, chemically-validated carotenoid quantification table (not the 10,949-feature untargeted table), using the same phylogenetic block-permutation framework already built for the untargeted analysis, and using colony area as the same decoy/negative-control trait already validated in the existing pipeline.
5. Cross-check: if torulene/torularhodin ratio (not absolute abundance) tracks a*/b* better than either alone, that's a chemically expected result (their color contribution differs — torularhodin's extended conjugation via the carboxyl and further oxidation shifts absorption redder) and would explain why a single-feature untargeted correlation could look null even with real biology underneath.

## Expected Insights
Either (a) a validated targeted assay shows the two known pigments genuinely don't track a*/b* well even under best-case detection — which would be a much stronger, publishable null than the current one, since it rules out the "assay blindness" objection reviewers will raise — or (b) the targeted assay recovers a real signal the untargeted pipeline missed, which would redirect the entire project (genome-color association becomes viable via carotenogenesis-pathway gene dosage/copy number in BFD, since CrtYB/CrtI/CrtS-type gene variation is a much cleaner genome-color hypothesis than whole-metabolome association).

## Feasibility
- Effort: Medium (extraction protocol is standard natural-products chemistry; instrument access for APCI/APPI-C30 may require a collaborator or core facility)
- Data ready: Needs new data (targeted extraction + reference standards; existing pellet fraction samples may already exist frozen and reusable)
- Methods available: Standard tools (classical carotenoid HPLC-APCI-MS is a mature, well-published method in food/fungal pigment chemistry — no custom algorithm development needed)
- Key risk: If archived pellet material is no longer viable (degraded pigment, insufficient biomass, or samples already consumed), this requires new fermentation/growth runs on a stratified strain subset, adding weeks of wet-lab time; also, sample number will necessarily be much smaller than n=300, so statistical power for weak effects will be limited — this idea directly tests "can we see the molecule at all," not exhaustive genome-wide association.

# Predicted-Mass Targeted Re-mining of the Existing Untargeted Data for Carotenogenesis Pathway Intermediates and Adducts

## Persona
**Natural Products / Analytical Chemist** — I know that most of what an LC-MS run actually contains never gets "identified" by default software defaults, and that re-mining raw data with chemistry-informed target lists routinely recovers compounds that untargeted feature-finding and library-matching pipelines silently drop or fragment into orphan peaks.

## Motivation
Before spending wet-lab time and instrument access on a brand-new extraction (Idea 1), the cheaper chemist move is to go back into the *existing* 594-sample LC-MS2 raw data with a hypothesis-driven target list, because carotenoids and their biosynthetic intermediates have well-known, calculable exact masses, common adducts, and diagnostic MS/MS neutral losses (e.g., sequential loss of 68 Da isoprene units, loss of toluene-92 Da fragments from cyclized rings, characteristic polyene UV-independent in-source fragmentation ladders) that a targeted extracted-ion-chromatogram (XIC) search can find even when they were never flagged as a "feature" by the automated peak-picker, and even when SIRIUS structural annotation failed on them.

## Connection to Existing Data
- The SIRIUS re-run is already underway by the PI "with additional reference data" — this idea is a complementary, much faster parallel track that doesn't wait on that re-run, using deterministic mass-matching instead of ML-based structure elucidation.
- 16,332 raw aligned features were deduplicated to 10,949 compound groups via adduct/isotope/in-source-fragment collapsing — carotenoids are exactly the molecule class most likely to have been mis-collapsed (their extensive in-source fragmentation and multiple isomeric forms, e.g., all-trans vs. various cis-torulene, could easily have been either wrongly merged into one non-representative group or split across many groups that individually look like noise and fail significance testing separately, diluting the true single-compound signal across multiple weak "features").
- The pathway is genetically well characterized in Rhodotorula/Rhodosporidium (crtYB, crtI, crtE/GGPP synthase, then torulene-specific and torularhodin-specific oxidase steps) — BFD's Pfam/functional annotation data (already fully populated for 276-278 strains) could in principle be cross-referenced for pathway gene presence/copy-number once candidate metabolite masses are confirmed, connecting the untapped genome dataset to this chemistry-first re-mining rather than leaving genome-color association completely unstarted.
- This directly interrogates whether the "4.8% annotation rate" and "only 3-4 weak carotenoid-class calls" reflect true biological absence or a computational annotation gap in a pipeline (EverythingBagel + SIRIUS) that was general-purpose, not carotenoid-tuned.

## Approach
1. Build an in-silico target list of exact masses (M, [M+H]+, [M+Na]+, [M+NH4]+, [M-H2O+H]+, [M-H]- for torularhodin's acid) for the full carotenogenesis pathway: GGPP, phytoene, phytofluene, ζ-carotene, neurosporene, lycopene, γ-carotene, β-carotene, torulene, torularhodin, and any known esterified/glycosylated forms reported in Rhodotorula literature.
2. Run targeted XIC extraction (5-10 ppm mass windows, appropriate RT range for a C40 lipid on whatever column was used) directly against the raw/converted LC-MS2 files for all 594 samples — bypassing the general feature-alignment and deduplication pipeline that may have discarded or fragmented these peaks.
3. For any XIC hit, manually inspect the MS2 spectrum for the diagnostic polyene fragmentation ladder (sequential losses characteristic of conjugated isoprenoid backbones) as orthogonal confirmation, since library/SIRIUS matching is untrustworthy here per the project's own observation.
4. Cross-reference confirmed-hit sample IDs against the "ms_feature_dedup_groups.csv" linked-data table to determine whether these compounds exist in the current 10,949-group table under a different, unflagged, or split identity — this would explain a false null directly (compound was tested, just not correctly attributed).
5. If confirmed peaks are found, re-run the existing Spearman/phylogenetic-permutation pipeline (already built and validated with the colony-area decoy) using only these newly-confirmed, chemically-validated carotenoid intensities as the exposure — fast because the statistical machinery already exists, only the input feature table changes.

## Expected Insights
This is a data-archaeology check on the existing null result before concluding "no carotenoid-color link exists": either the targeted re-mining finds nothing at any pathway mass (strong evidence the pigments truly are below LOD or absent under these growth/extraction conditions — mechanistically interesting on its own, e.g., maybe these Rhodotorula strains predominantly express non-carotenoid pigments like melanin/pulcherrimin/flavins under this specific growth medium), or it recovers real pathway-intermediate signal that was present all along but mis-annotated/orphaned by generic feature-picking — which would mean the 5 null statistical tests were run on the wrong exposure variable, not that the color-metabolome link is absent.

## Feasibility
- Effort: Low (no new wet lab, no new instrument time — reuses existing raw data and existing statistical pipeline)
- Data ready: Mostly (raw/converted LC-MS2 files should already exist from the original acquisition; needs the exact-mass target list built and an XIC-extraction script, likely a short Python/R script using an existing mzML-parsing library)
- Methods available: Standard tools (targeted XIC extraction against exact mass + RT window is routine metabolomics practice; no novel algorithm needed), though manual MS2 fragment interpretation for polyene ladders benefits from someone with hands-on carotenoid MS experience
- Key risk: If the original chromatography/ionization mode genuinely cannot retain or ionize C40 carotenoids at all (e.g., reversed-phase C18 with standard ESI and no lipid-optimized gradient), targeted re-mining of the *existing* data will also come back empty — in which case this result should be read as "confirms Idea 1 is necessary," not as new evidence of biological absence.
